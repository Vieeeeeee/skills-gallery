- 🎨 **1,000+ Production-Grade Visual Prompts**  
  Curated across **12 major design aesthetics** including Traditional Chinese Ink Wash, Paper Collage, Minimalist Deconstructivism, Watercolor Illustration, Manga Pop Art, Cinematic AI Video, and more. Each entry is rigorously tested with real rendering samples, offering **one-click copy of full prompt recipes and camera movement parameters**.
- ⚡ **Out-of-the-Box Agent Skills Ecosystem**  
  Deeply tailored for modern agentic workflows like Claude Code, Cursor, OpenAI Codex, and Google Antigravity. Features dozens of battle-tested community skills with **one-click installation commands and comprehensive scenario guidelines**.
- 📖 **MengTo-Inspired 3D Interactive Design Sketchbook**  
  Breaking away from repetitive grid cards to faithfully recreate an **interactive physical designer sketchbook** — complete with dual-page book spine stitching, cold-pressed watercolor bleeding edges, cinnabar stamps, spring physics page-flipping algorithms, and a draggable **3D Brass Magnifying Loupe** for microscopic brushwork inspection.
- 🌓 **Dual Minimalist Aesthetics (Light & Dark)**  
  Artfully calibrated natural warm-paper textures for daytime reading, paired with a sleek cyber dark mode, dynamically syncing with your operating system preferences or toggleable with a single click.
- 🔍 **Multi-Dimensional Smart Tag Matrix & Search**  
  Over 200+ design style and technical tags organized into a flexible pill navigation system. Enjoy millisecond-fast fuzzy search, stream filtering, persistent local bookmarks, and one-click shuffle exploration.
- 🚀 **100% Zero-Backend Static Architecture**  
  Pure frontend client-side execution powered by Vite + React 19. No database maintenance, zero hosting fees, global edge CDN distribution with instant load times, and **1-Click zero-ops deployment on Cloudflare Pages, Vercel, or GitHub Pages**.

## 🛠️ Local Development & Quickstart

Prerequisites: Standard Node.js environment (Node >= 18 recommended).

```bash
# 1. Clone the repository
git clone https://github.com/Vieeeeeee/skills-gallery.git
cd skills-gallery

# 2. Install dependencies
npm install

# 3. Start local development server (Instant HMR)
npm run dev
```

Visit `http://localhost:5173` to explore the gallery locally.

### Production Build & Data Integrity Check

```bash
# Validate format and completeness of 1,000+ curated items
npm run validate:data

# Production build
npm run build
```

## 🚀 1-Click Zero-Ops Deployment

### Deploy to Cloudflare Pages (Recommended)
This repository is configured for automatic Cloudflare Pages deployment:
```bash
# Build & Deploy in one step
npm run build
npx wrangler pages deploy dist --project-name=skills-gallery
```

### Deploy to Vercel
Import the GitHub repository into your Vercel dashboard. Vercel will automatically detect the Vite build configuration and host it with edge caching.

## 🏷️ Originality Protection & Author Claim Policy

We staunchly defend and honor the intellectual efforts and attribution rights of every creator:

1. **Source & Attribution Transparency**:  
   This repository aims to aggregate and promote cutting-edge AI aesthetics. For early entries collected through community discussions where the original author could not be verified, they are temporarily designated as *"开源社区 (Open Source Community) / 网络整理 (Web Curated)"*;
2. **One-Click Author Claim Pipeline**:  
   If you are the original creator of any visual prompt recipe or Agent Skill, please visit our 👉 **[Author Claim Channel](../../issues/new?template=claim_author.yml)** to submit proof of publication (e.g., timestamped posts on X, Xiaohongshu, WeChat, or blogs). Upon verification, we will update the official author attribution and feature your personal profile within 24 hours!
3. **24-Hour Takedown Guarantee**:  
   If you are the original creator and prefer your work not to be indexed, please open an Issue. We guarantee an unconditional **modification or takedown within 24 hours**.
